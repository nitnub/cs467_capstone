# Build an Emulator and Run Space Invaders ROM (OSU CS 467 Capstone Project, Summer 2026)

A complete Intel 8080 emulator, built with input, audio, and video support to run the original Space Invaders.

## How to play

(Note: the inputs are **not** case-sensitive)

### Menu controls
| Up | Down | Select | Quit | 
|---|---|---|---|
| `↑` | `↓` | `Enter/Return` | `Q` `Esc` |

### Shared controls
| Insert Coin | Tilt | Quit | 
|---|---|---|
| `C` | `T` | `Esc` |

### Game controls

| | Left | Right | Fire | Start |
|---|---|---|---|---|
| Player 1 | `←` | `→` | `Space` | `1` |
| Player 2 | `A` | `D` | `Enter` | `2` |
